# more/ — extra songs

Drop **MP3** files here (only `.mp3` is read). Any file name works, for example `my_song.mp3`.

When the main song of a party ends, the game plays a random song from this folder (never the same one twice in a row).
If the folder is empty, the built-in synthesised music is used.

The songs are not included in the repository (they may be copyrighted); add your own.
