# DJ/ — songs after the DJ dies

Drop **MP3** files here (only `.mp3` is read). Any file name works, for example `punk_1.mp3`.

Once the DJ of a party is dead, the game switches to a random song from this folder (the original game switches to punk rock).
If the folder is empty, the built-in synthesised music is used.

The songs are not included in the repository (they may be copyrighted); add your own.
