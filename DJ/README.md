# DJ/ — songs after the DJ dies

Drop **MP3** files here (only `.mp3` is read). Any file name works, for example `my_song.mp3`.

Once the DJ of a party is dead, the game switches to a random song from this folder.
If the folder is empty, the built-in songs written for that moment play instead (fast funk, big beat, ska, salsa,
disco funk and surf rock; never the same one twice in a row).

Older versions generated `punk_1.mp3` ... `punk_6.mp3` here. They are no longer used nor shipped: delete them
(an update patch lists them in REMOVIDOS.txt); if a copy is left, it is ignored.

The songs are not included in the repository (they may be copyrighted); add your own.
